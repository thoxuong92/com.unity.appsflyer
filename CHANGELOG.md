# Changelog

All notable changes to this package will be documented in this file.

## [1.0.0] - 2026-08-25
### Added
- Standardized package structure for Unity Package Manager (UPM).
- Integrated `AppsFlyerTrackingProvider` implementing `Unity.Core.Services.Tracking.ITrackingProvider` & `Unity.Core.Services.Analytics.IAnalyticsProvider`.
- Added Impression-Level Ad Revenue logging support via `AppsFlyer.logAdRevenue`.
- Added `AppsFlyerEditorWindow` for configuration management.
- Included official AppsFlyer Unity Plugin v6.16.2.
- Added `link.xml` for IL2CPP stripping safety.
